# BULLETPROOF

An ASCII parkour + hacking game. You are a rogue AI. Bullets are only data.

```
```

| Key | Action |
|---|---|
| A / D | move |
| W / Space | jump (hold for height) |
| S | drop through `=` platforms |
| Q | bubble (bullet time) |
| E | use terminal |
| ESC | disconnect from terminal |
